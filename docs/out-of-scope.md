# Out of Scope (v1)

- Hosted web services, account/licensing backend, and production-server integrations.
- Cloud document sync of any kind — offline-first is the target, matching [Purpose & Scope](purpose-and-scope.md).
- Mobile builds — desktop only for v1 (Tauri does support mobile later, if ever needed).
- Pixel-identical UI to the Qt/QML original — behavioral and file parity are the targets, not visual cloning.
